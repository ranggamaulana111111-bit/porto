## Temuan

### HIGH (Hard Gate)

**1. R-25 Kontras gagal pada teks `text-online` dan pill accent tipis**
- `app/messages/page.tsx:308` memakai `text-online` (#2e9d7a) untuk normal text ("Pesan tampil…") di latar putih → 3.38:1, **gagal** AA normal text (hanya lolos large text).
- `catatan.tsx:27/38/49/60` dan `command-palette.tsx:235` memakai `bg-accent/10 text-accent` untuk pill aktif (text `text-xs`) → 4.42:1, di bawah 4.5 (marginal).
- Fix cepat: ganti `--color-online` ke `#1d7a5a` (5.27:1 LOLOS) di globals.css + sinkronkan DESIGN.md, atau pakai `text-accent-strong` untuk teks sukses dan pill aktif.

**2. R-03 (layoutmobile) Target sentuh di bawah 44px**
- Hamburger navbar `h-9 w-9` = 36px (navbar.tsx:120).
- Tombol ⌘K `px-2.5 py-1.5 text-[11px]` ≈ 27px (navbar.tsx:103).
- CTA hero `py-2.5` ≈ 42px (hero.tsx:93-105).
- Naikkan minimum ke `h-11` / `min-h-[44px]` untuk kontrol utama yang jadi satu-satunya akses (hamburger, ⌘K), dan periksa semua tombol sentuh.

### MEDIUM (Purpose-Gate)

**3. R-31/C-1 Campur bahasa EN/ID di UI — sekarang melanggar DESIGN.md tertulis**
DESIGN.md baris 91-92 menetapkan copy "Indonesian, plain", tapi UI paling terlihat masih Inggris:
- Nav (FALLBACK_NAV, lib/content.ts:330-339): "Home, About, Projects, Experience, Skills, Workspace, Contact" — 6 dari 8 label Inggris.
- Hero CTA: "View CV" (hero.tsx:95), "View Projects" (101), "Explore Workspace →" (107) — dan penggunaan panah tidak merata (hanya "Explore Workspace" yang berpanah).
- ProfileSnapshot hardcoded EN (profile-snapshot.tsx:6-10): "Location / Education / Focus / Currently / Open to", dan tidak membaca content.json (C-3).
- Eyebrow section: "Selected Projects", "Experience", "Education", "Technical Stack", "Currently Learning", "Contact", "Digital Workspace", "Live Project" (project-detail.tsx:88), "Diagram" (project-detail.tsx:111).
- Arahkan satu suara: terjemahkan label menu/eyebrow/CTA ke Indonesia (Home→Beranda, View CV→Lihat CV, dsb.) dan pindahkan data profil ke content.json. Perlu dicek siapa yang paling sering terlihat: nav dan hero.

**4. R-26 Command palette arah item project salah sasaran**
- command-palette.tsx memanggil `goTo("projects")` untuk item project → di homepage scroll ke section `#projects` (gallery), bukan membuka halaman `/project/[slug]`. Di subhalaman router.push ke `/#projects` (lompat ke homepage). Item di palette berlabel nama project sehingga pengguna berharap membuka project itu sendiri.
- Fix: untuk `type === "project"` gunakan `router.push(\`/project/${item.id}\`)`.

**5. R-31 Token CSS tidak terdefinisi + ternari mati (lanjutan #15 audit-001)**
- `bg-bg-elevated`: dipakai di project-detail.tsx:121 (blok alur persetujuan Prodesa yang RENDER) dan framed-snippet.tsx:27 — token tidak ada di `@theme`, jadi latar blok jatuh ke transparan tanpa maksud.
- `border-accent-muted/40` dan `hover:bg-accent-muted/30`: navbar.tsx:77 dan 157 — token `accent-muted` tidak ada, jadi highlight item nav "Workspace" tidak pernah tampil.
- `navbar.tsx:62`: ternary `scrolled` dua cabang identik (tidak melakukan apa-apa).
- Hapus kelas mati atau tambahkan token-nya; singkirkan ternary yang identik.

**6. C-2 Dead code masih utuh (lanjutan #16 audit-001)**
