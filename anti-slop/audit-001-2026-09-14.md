## Temuan

### HIGH (Hard Gate)

**1. R-02 Em dash (—) dipakai masif di copy UI**
Karakter `—` tersebar di copy yang dirender: hero.tsx:84, currently-learning.tsx:17, technical-stack.tsx:25, selected-projects.tsx:24, experience.tsx:16, education.tsx:19/25/41, content.json (intro, journey, howIWork, project challenge/summary/learnings/caption, plans), workspace/page.tsx, stack/page.tsx:117, cv/page.tsx, project-detail.tsx:135, catatan.tsx:111, rencana.tsx:14, yang-sedang-dibangun.tsx (4x). Ganti dengan koma, titik dua, atau tanda kurung.
Catatan penting: `content.json` di-refetch dari GitHub saat build (`scripts/fetch-content.mjs`, repo `ranggamaulana111111-bit/porto`), jadi perbaikan em dash di content.json lokal bisa tertimpa. Sumber di GitHub harus diperbaiki juga, atau fetch-source tersebut disesuaikan.

**2. R-24 + R-26 Command palette punya item project yang tidak berfungsi**
command-palette.tsx:86 memanggil `scrollToId("project")` untuk semua item project, padahal section homepage ber-id `projects` (selected-projects.tsx:16), bukan `project`. `getElementById("project")` null, jadi memilih project dari palette tidak melakukan apa-apa. Item section juga mati di semua subhalaman (/workspace, /stack, /cv, /project/...) karena elemen id-nya tidak ada di halaman itu.

**3. R-26 Link "Kembali ke project" menuju anchor yang tidak ada**
project-detail.tsx:59 `href="/#project"`. Tidak ada elemen ber-id `project` di homepage (yang ada `#projects`), jadi klik langsung jatuh ke atas homepage, bukan ke daftar project.

**4. R-37 Tidak ada DESIGN.md dan dial tidak dideklarasikan**
Tidak ada file DESIGN.md di repo. Identitas visual sudah jelas (clay hangat), tapi tidak ada catatan tertulis soal alasan, dan tidak ada deklarasi dial ENERGY / RHYTHM / MOTION. Hasil desain tanpa arahan tertulis = draft yang tidak terdokumentasi. Solusi: buat DESIGN.md yang merekam identitas yang sudah ada beserta dial-nya, bukan desain ulang.

**5. R-17 + R-36 Metrik project disajikan sebagai fakta tanpa sumber di dalam halaman**
Contoh: "100 Lighthouse", "<1s Load Time", "35 Iterasi Ping" (cp-chilva + alkonekplus), "20 Rubrik", "10 Fase", "4 Brand OLT". Kemungkinan besar nyata (data milik pemilik), tapi halaman tidak menautkan bukti/sumber. Sertakan tautan bukti (screenshot repo/live) atau hapus.

**6. R-03 `overflow-x: hidden` di body menutupi bug mobile, bukan memperbaikinya**
globals.css:57. Overflow horizontal yang seharusnya dibereskan di layout jadi disembunyikan. Responsive belum sempat diverifikasi lewat klik menyeluruh (R-35 belum jalan karena audit inspeksi kode). Perlu pass pendeteksi overflow sungguhan, bukan masking.

### MEDIUM (Purpose-Gate)

**7. R-06 Label mono uppercase + tracking lebar jadi default berulang di tiap section**
Pola `font-mono text-xs uppercase tracking-wider text-fg-muted` dipakai di hampir semua section homepage dan subhalaman ("SELECTED PROJECTS", "TECHNICAL STACK", "MENDENGARKAN", "LOCATION", dst.). Analogue dari "HOW IT WORKS / FEATURES". Alasan sistem label ini tidak tertulis. Kalau memang label sistem, tuliskan alasannya.

**8. R-05 Rhythm section seragam + section tumpang tindih**
Hampir semua section homepage = label mono + heading display + paragraf + grid/list berulang (SelectedProjects, TechnicalStack, WhatImLearning, Experience, Education, Contact). Komposisi tidak bervariasi. Ditambah tumpang tindih konten antar WhatImLearning, CurrentlyLearning, dan TechnicalStack (Next.js, Docker, Linux, Security muncul berulang di 2+ section), sehingga beberapa section tidak punya tujuan konten yang unik (C-3).

**9. R-19 Semua animasi = fadeUp yang sama, dan tidak ada dial MOTION**
Reveal default ke fadeUp; semua section memakai pola yang identik (`opacity 0 + y 20`, durasi sama). Belum ada MOTION dial untuk membenarkan pola ini. Seragam itu boleh kalau "MOTION 1" memang dideklarasikan, tapi sekarang tidak.

**10. R-08 Panah sebagai dekorasi default**
"→" di hero ("Explore Workspace →"), workspace ("Lihat Stack →"), footer ("Workspace →"), navbar mobile; ArrowUpRight di hampir semua link eksternal/GitHub/Live. Digunakan sebagai tanda "link keluar" tapi asosiasinya tidak konsisten (ada yang ke halaman internal, ada yang eksternal). Alasan pemakaian tidak tertulis.

**11. R-11 Radius pill dipakai untuk semua elemen interaktif**
Buttons, tags, badges, nav link, chip status, badge tahun semuanya `radius-pill`, sementara kartu memakai radius clay besar. Sistem ini konsisten (mungkin identitas clay), tapi jatuh ke pola "semua pill" tanpa alasan tertulis. Tuliskan alasan sistem radius-nya.

**12. R-01/R-07 SVG dekoratif wallpaper latar di layout.tsx:114-143**
Garis lengkung + isian ombak 2.5%-5% opacity yang menutupi seluruh halaman sebagai ambient background. Tidak ada tujuan identitas tertulis. Samar dan tidak mungkin merusak, tapi tetap perlu alasan yang ditulis (atau dihapus).
